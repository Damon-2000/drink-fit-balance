# 醉後比較功能規格

## Document Information

- Document Type: Product Specification
- Status: Approved
- Last Updated: 2026-11-06
- 來源：學生提交的需求、規格、操作流程與線稿，經講師審查補強。

## Scope

本文件定義 醉後比較 的功能需求、業務規則，以及前端與瀏覽器本地儲存（localStorage）的職責分工。

醉後比較是一個以「熱量控制」為目的的飲酒紀錄工具：使用者逐杯登記飲酒內容，系統把酒精飲料的熱量換算成運動代償，或以「血量」呈現與今日熱量目標的差距。本專案為學生個人練習與自用，不作為商品發佈。

第一版不包含：

- 後端服務、登入、雲端同步與多裝置共用。
- 多輪歷史紀錄與統計圖表（只保留前一輪紀錄）。
- 使用者自訂酒款、自訂容器與自訂運動（需要新增時直接修改靜態資料檔）。
- 生理影響的量化數值（睪固酮、皮質醇等只以固定文字呈現）。
- 代償運動的隨機抽選與「隨機規則頻率跟狀態做連結」。
- 每杯送出前的確認或警告視窗。
- 桌機專用版型。

## 系統組成

```text
┌──────────────────────────── 瀏覽器 ────────────────────────────┐
│                                                                │
│  前端網頁（Next.js）                                            │
│    ├─ 靜態資料：酒款表、容器表、運動表（隨專案打包，唯讀）        │
│    ├─ 計算：每杯熱量、累計熱量、運動代償、血量判定                │
│    └─ 畫面：首頁、設定、模式選擇、登記、待機、結果                │
│                       │                                        │
│                       ▼                                        │
│  localStorage：身高體重、運動開關、本輪紀錄 / 前一輪紀錄           │
│                                                                │
└────────────────────────────────────────────────────────────────┘
無後端、無外部服務。
```

## Functional Requirements

| 編號 | 模組 | 功能項目 | 規格描述 | 來源 |
| ---- | ---- | -------- | -------- | ---- |
| 1 | 使用者模式選擇 | 首次進入首頁 | 沒有前一輪紀錄時，首頁顯示產品名稱「醉後比較」、標語「飲酒X健康不耽誤!!」與「開始」按鈕。 | 學生 |
| 2 | 使用者模式選擇 | 前一輪紀錄檢視 | 有前一輪紀錄時，首頁顯示前一輪紀錄的摘要與「重新開始」按鈕。前一輪紀錄只供檢視，不可繼續登記。 | 學生、講師補強 |
| 3 | 使用者模式選擇 | 重新開始確認 | 按「重新開始」時，提示「即將清除前一輪紀錄並開始新的一輪」。確認後清除前一輪紀錄並進入下一步；取消則留在首頁，紀錄不變。 | 講師補強 |
| 4 | 使用者模式選擇 | 首次輸入身高體重 | 尚未設定身高與體重時，按「開始」後必須先輸入身高（cm）與體重（kg）並送出，才能進入模式選擇；已設定過則直接進入模式選擇。 | 學生 |
| 5 | 使用者模式選擇 | 身高體重範圍 | 身高有效範圍 100–250 cm、體重 30–250 kg；任一欄位空白或超出範圍時不可送出，並在欄位旁顯示原因。 | 講師補強 |
| 6 | 使用者模式選擇 | 選擇模式 | 模式選擇畫面提供兩種模式：「醉後回本（有健身習慣）」標示為輕鬆挑戰；「醉後底線（有體態控制需求）」標示為困難挑戰。選擇後進入對應流程。 | 學生 |
| 7 | 使用者模式選擇 | 設定入口 | 首頁、模式選擇、登記、待機與結果畫面的右上角都有「設定」按鈕，開啟設定面板。 | 學生 |
| 8 | 使用者模式選擇 | 運動代償類型 | 設定面板可逐項開啟或關閉運動表中的運動，數量不限；全部關閉時視同全部開啟。設定套用到所有模式與畫面。 | 講師補強 |
| 9 | 使用者模式選擇 | 修改身高體重 | 設定面板可修改身高與體重，範圍同需求 5。修改後，之後的運動代償以新體重計算。 | 學生 |
| 10 | 酒款輸入與選擇 | 選擇酒款 | 登記畫面的酒款欄可下拉選擇，或輸入文字篩選酒款表；只能選擇酒款表中的酒款，不提供自訂酒款。 | 學生、講師補強 |
| 11 | 酒款輸入與選擇 | 隨機酒款 | 按「隨機」從酒款表抽出一款，並帶入該酒款的預設杯數與預設容器；不滿意可再按「隨機」重抽，也可以手動修改酒款、杯數與容器。 | 學生 |
| 12 | 酒款輸入與選擇 | 沿用上一杯 | 按「沿用上一杯」帶入上一筆登記的酒款、杯數與容器，帶入後仍可修改。 | 學生 |
| 13 | 酒款資料設定 | 杯數 | 登記畫面可選擇或輸入杯數。 | 學生 |
| 14 | 酒款資料設定 | 容器與容量 | 登記畫面從容器表選擇容器（例如啤酒杯大、中、小、調酒杯、shot 杯）；選項以 ml 顯示容量，並附註 fl oz。 | 學生、講師補強 |
| 15 | 酒款資料設定 | 加入清單 | 酒款、杯數與容器都已填寫時才能按「送出」；送出後加入本輪飲酒清單，並切換到待機畫面。 | 學生 |
| 16 | 飲酒紀錄管理 | 每筆熱量 | 每一筆登記的熱量，依酒款表的熱量資料、容器容量與杯數計算。 | 學生、講師補強 |
| 17 | 飲酒紀錄管理 | 待機畫面紀錄 | 待機畫面顯示本輪累計杯數與累計熱量；按「再一杯」回到登記畫面，按「結束」進入結果畫面。 | 學生 |
| 17a | 飲酒紀錄管理 | 0 杯時取消 | 本輪還沒有任何登記時，登記與待機畫面的「結束」改為「取消」；按下後不產生紀錄，直接返回首頁。 | 講師補強 |
| 18 | 飲酒紀錄管理 | 刪除最後一杯 | 待機畫面可刪除本輪最後一筆登記，刪除後累計數值立即更新。 | 講師補強 |
| 19 | 飲酒紀錄管理 | 紀錄保存 | 本輪紀錄保存在瀏覽器本地；結束後成為「前一輪紀錄」。只保留一輪，開始新的一輪時清除前一輪（見需求 3）。 | 講師補強 |
| 19a | 飲酒紀錄管理 | 回到進行中的一輪 | 本輪尚未結束時重新整理或關閉後再開啟網頁，直接回到進行中的這一輪，已登記的內容、模式與血量都不變。 | 講師補強 |
| 20 | 運動代償計算 | 運動換算 | 依運動表資料與使用者體重，把熱量換算成每一項已開啟運動所需的時間；換算公式與運動資料由學生依附錄格式提供。 | 學生、講師補強 |
| 21 | 運動代償計算 | 醉後回本：即時換算 | 醉後回本的登記與待機畫面，顯示本輪累計熱量換算成 1 項運動所需的時間；這 1 項為運動表順序中第一個已開啟的運動。 | 學生、講師補強 |
| 22 | 運動代償計算 | 醉後底線：設定血量 | 醉後底線開始前，輸入今日熱量目標（血量，單位 kcal），有效範圍 1–5000；空白或超出範圍時不可按「開始挑戰」。 | 學生、講師補強 |
| 23 | 運動代償計算 | 醉後底線：扣血 | 每送出一筆登記，就直接以該筆熱量扣除血量，不顯示確認或警告視窗；登記與待機畫面顯示剩餘血量（kcal）與剩餘百分比。 | 學生、講師補強 |
| 23a | 運動代償計算 | 醉後底線：低血量提示 | 剩餘血量百分比低於門檻時，剩餘血量的顯示改為警示樣式（例如變色）；門檻值定義在 config，暫定為 20%。 | 講師補強 |
| 24 | 結果呈現 | 醉後回本總結 | 結束後顯示本輪總結：杯數、各酒款熱量、總熱量，以及總熱量換算成每一項已開啟運動所需的時間（數量不限）。 | 學生、講師補強 |
| 25 | 結果呈現 | 醉後底線判定 | 結束時，本輪總熱量「大於」血量判定為挑戰失敗，等於或小於血量判定為挑戰成功。 | 學生、講師補強 |
| 26 | 結果呈現 | 醉後底線失敗報表 | 先顯示失敗提示，再顯示報表：超過多少 kcal、杯數、各酒款熱量與扣血、熱量最高兇手、生理影響說明文字（睪固酮降低、皮質醇升高）、總熱量的運動代償。 | 學生 |
| 27 | 結果呈現 | 醉後底線成功報表 | 先顯示恭喜挑戰成功，再顯示報表：剩餘多少 kcal、杯數、各酒款熱量與扣血、熱量最高兇手、補充水分防禦說明文字、剩餘熱量換算、總熱量的運動代償。 | 學生 |
| 28 | 結果呈現 | 熱量最高兇手 | 熱量最高兇手為本輪累計熱量最高的酒款；同分時取最早加入的那一款。 | 學生、講師補強 |
| 29 | 結果呈現 | 數值精度 | 熱量（kcal）與運動時間（分鐘）一律四捨五入到整數顯示。 | 講師補強 |
| 30 | 結果呈現 | 返回主畫面 | 結果畫面的「返回主畫面」回到首頁，首頁顯示這一輪成為前一輪紀錄（需求 2）。 | 學生 |
| 31 | 共通 | 版型 | 以手機為主，最小寬度 375px；桌機瀏覽時內容置中，最大寬度 480px。 | 講師補強 |

## Service Boundaries

| 功能 | 前端網頁 | 瀏覽器本地儲存（localStorage） | 靜態資料檔 |
| ---- | -------- | ------------------------------ | ---------- |
| 身高體重 | 顯示、編輯、檢查範圍 | 保存身高、體重 | — |
| 運動代償類型 | 顯示、切換開關 | 保存開關狀態 | 提供運動清單 |
| 模式選擇 | 顯示、發出選擇 | 保存本輪模式 | — |
| 酒款選擇、隨機、沿用上一杯 | 顯示、篩選、隨機抽選 | 讀取本輪上一筆 | 提供酒款表 |
| 杯數與容器 | 顯示、編輯 | — | 提供容器表 |
| 飲酒清單 | 顯示、新增、刪除最後一筆 | 保存本輪清單與醉後底線血量 | — |
| 熱量與運動代償計算 | 依靜態資料與清單計算、顯示 | — | 提供熱量與運動換算資料 |
| 醉後底線判定與報表 | 計算判定、顯示報表 | — | 提供報表說明文字（若放在資料檔） |
| 前一輪紀錄 | 顯示、確認後清除 | 保存一輪紀錄 | — |

本專案沒有後端，前端與 localStorage 即為資料的權威來源；這只適用於個人自用的練習情境。

| 資料 | 需要表達 | 用途與限制 |

**建議的計算方式**（正式公式由學生提供，講師確認後寫入需求表）

## 待確認事項

- 酒款表、容器表、運動表的正式內容與資料來源為何？（學生提供，講師審核）
- 運動代償的正式換算公式是否採用附錄建議的 MET 公式？身高是否參與任何計算？
- 杯數的有效範圍為何？是否允許半杯等小數？
- 「沿用上一杯」在本輪還沒有任何登記時，是否可以沿用前一輪的最後一筆，還是停用？
- 醉後底線低血量提示的正式門檻值是否維持 20%？
- 醉後回本畫面上的「警告」要呈現什麼內容、在什麼條件下出現？
- 醉後底線成功報表的「剩餘熱量換算」要換算成什麼（運動時間或其他）？
- 失敗與成功報表的說明文字（睪固酮、皮質醇、補充水分防禦）內容為何？由誰撰寫？
- 醉後底線設定血量畫面中間的圖片佔位，要放什麼內容？
